# HOEJENE — Technology & Electronics

**Innovation for a Connected Future.**

Modern, responsive, multi-page technology brand demonstration.

## Pages
- Home (`index.html`)
- Products (`products.html`) — live search and category filters
- Categories (`categories.html`)
- Innovations (`innovations.html`)
- About (`about.html`)
- Contact (`contact.html`) — demonstration only
- FAQ (`faq.html`)
- Privacy Policy (`privacy.html`)
- Terms (`terms.html`)

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this directory.

## GitHub Pages
Upload the **contents** of this folder (not the enclosing folder) to the root of `hoejene-website`. In repository Settings → Pages, select Deploy from a branch → main → / (root).

Planned URL: https://hoejene.github.io/hoejene-website/

## Brand palette
- Midnight Navy `#0F172A`
- Electric Blue `#3B82F6`
- White `#FFFFFF`

## Important
All products are fictional concepts. No real orders, payments, customer accounts or contact form submissions are supported. Fonts use Google Fonts when internet access is available; system fonts are used otherwise.
