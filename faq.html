HELP / FAQ

Questions, answered.

Helpful information about the HOEJENE concept website.

Can I purchase products through HOEJENE?

No. The current website is a brand and product-concept demonstration. There is no live inventory, checkout, or payment service.

Are the products real?

The displayed products are fictional illustrations of possible technology categories, not verified commercial products.

Does the contact form send emails?

No. The form demonstrates the user interface only and does not send or store messages.

Is the website mobile friendly?

Yes. The layout adapts to desktop, tablet and mobile screen sizes.

How can I follow development?

Visit the HOEJENE GitHub repository for project updates.
